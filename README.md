# 🚖 SpotMe - Ride Sharing Application

**Developer**: Sandile Rasimeni  
**GitHub**: https://github.com/sandilerasimeni  
**Platform**: Android  
**Language**: Java  
**Database**: SQLite  
**Files**: 13 Java classes

## Project Overview
Complete ride-sharing app with passenger and driver interfaces. Features real-time ride matching, user authentication, and database management.

## Files Included:
1. DatabaseHelper.java - SQLite database manager
2. LoginActivity.java - User authentication
3. PassengerHomeActivity.java - Passenger dashboard
4. DriverHomeActivity.java - Driver interface
5. RequestRideActivity.java - Ride booking
6. Ride.java - Ride data model
7. User.java - User model
8. Passenger.java - Passenger model
9. Driver.java - Driver model
10. Vehicle.java - Vehicle model
11. RideAdapter.java - Ride history adapter
12. RideRequestsAdapter.java - Ride requests adapter
13. DebugActivity.java - Debugging tool

## Setup:
1. Clone repository
2. Open in Android Studio
3. Run on emulator
